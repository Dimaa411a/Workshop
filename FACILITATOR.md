# Інструкція для організатора

## Перед воркшопом

1. Створи порожній публічний репозиторій `maine-coon-workshop` на GitHub (без README, без .gitignore).
2. Завантаж цей проєкт туди. Це заодно хороша демонстрація для старту:

   ```bash
   cd maine-coon-workshop
   git init
   git add .
   git commit -m "Перший коміт: лендінг про мейн-кунів"
   git branch -M main
   git remote add origin https://github.com/ТВІЙ-НІК/maine-coon-workshop.git
   git push -u origin main
   ```

3. Увімкни GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**. Тоді прийняті PR одразу з’являтимуться на живому сайті, і це дуже мотивує.
4. Заміни `ОРГАНІЗАТОР` у `README.md` (крок 9) на свій нік, закоміть і запуш.
5. Попроси учасників заздалегідь зареєструватися на GitHub і встановити Git. Налаштування на місці з’їдає найбільше часу.

## Під час воркшопу

- **Мердж PR на проєкторі.** Покажи вкладку **Files changed**, залиш коментар, натисни **Merge**. Потім онови сайт на Pages: усі бачать своїх котів.
- **Живий конфлікт.** Усі учасники додають котів у кінець одного масиву в `data/cats.js`, тому після перших мерджів наступні PR почнуть конфліктувати. Не лякайся: це ідеальний момент показати кнопку **Resolve conflicts** прямо в інтерфейсі GitHub. У маркерах треба залишити обидва блоки котів і перевірити коми.
- **Типові проблеми:**
  - сторінка порожня після додавання кота → синтаксична помилка в `cats.js` (пропущена кома, лапка або дужка). Відкрий консоль браузера (F12);
  - `Permission denied` при push → людина клонувала оригінал, а не свій fork. Виправити: `git remote set-url origin https://github.com/ЇЇ-НІК/maine-coon-workshop.git`;
  - не приймає пароль → потрібен вхід через браузер, `gh auth login` або токен;
  - відкрився Vim після `git commit` без `-m` → `Esc`, `:wq`, `Enter`.

## Ідеї для продовження

- Попроси учасників відкрити **Issue** з ідеєю для сайту, а потім закрити його своїм PR (`Closes #номер` в описі).
- Додай правило захисту гілки `main` (Settings → Branches), щоб показати, як у командах забороняють push напряму.
