# Шпаргалка Git

## Налаштування (один раз)

| Команда | Що робить |
|---|---|
| `git config --global user.name "Ім’я"` | Ім’я для підпису комітів |
| `git config --global user.email "пошта"` | Пошта для підпису комітів |
| `git --version` | Перевірити, що Git встановлений |

## Почати роботу

| Команда | Що робить |
|---|---|
| `git clone URL` | Завантажити репозиторій з GitHub |
| `git init` | Зробити поточну папку новим репозиторієм |

## Щоденний цикл

| Команда | Що робить |
|---|---|
| `git status` | Що змінено і що готово до коміту |
| `git diff` | Показати зміни рядок за рядком |
| `git add файл` | Додати файл у staging |
| `git add .` | Додати всі зміни |
| `git commit -m "повідомлення"` | Зберегти знімок у історії |
| `git commit -am "повідомлення"` | `add` + `commit` для вже відстежуваних файлів |
| `git push` | Відправити коміти на GitHub |
| `git pull` | Забрати і влити нові коміти з GitHub |

## Історія

| Команда | Що робить |
|---|---|
| `git log` | Повна історія комітів (`q` — вихід) |
| `git log --oneline` | Коротка історія |
| `git show хеш` | Що змінив конкретний коміт |

## Гілки

| Команда | Що робить |
|---|---|
| `git branch` | Список гілок, `*` — поточна |
| `git switch -c назва` | Створити гілку і перейти в неї |
| `git switch назва` | Перейти в існуючу гілку |
| `git merge назва` | Влити гілку в поточну |
| `git push -u origin назва` | Перший push нової гілки |
| `git branch -d назва` | Видалити гілку після злиття |

## Remote

| Команда | Що робить |
|---|---|
| `git remote -v` | Список підключених remote |
| `git remote add upstream URL` | Підключити оригінальний репозиторій |
| `git pull upstream main` | Забрати зміни з оригіналу |

## Ой, щось пішло не так

| Ситуація | Команда |
|---|---|
| Зіпсував(ла) файл, хочу повернути як було в останньому коміті | `git restore файл` |
| Додав(ла) у staging зайве | `git restore --staged файл` |
| Помилка в повідомленні останнього коміту (ще не push) | `git commit --amend -m "нове повідомлення"` |
| Застряг(ла) в екрані `log` або `diff` | натисни `q` |
| Відкрився дивний редактор Vim | натисни `Esc`, набери `:wq`, натисни `Enter` |
| Почався merge з конфліктом, хочу скасувати | `git merge --abort` |

## Цикл роботи з чужим проєктом

```
Fork → clone → switch -c гілка → зміни → add → commit → push → Pull Request
```
